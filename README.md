# Ensemble Models Performance Comparison

This repository contains a machine learning project focused on comparing predictive models and ensemble methods under a structured evaluation framework.

The main objective of the project is to analyze how different modelling approaches perform on the same prediction task, assess the impact of hyperparameter tuning, and explore how ensemble techniques can improve predictive performance beyond individual models.

## Project overview

This project was developed as part of my academic work in machine learning and predictive modelling. It focuses on building, comparing, and evaluating different models in order to better understand their performance, trade-offs, and suitability for structured prediction problems.

The project includes model training, parameter tuning, performance comparison, and interpretation of results using a notebook-based workflow.

## Main components

This repository includes:

- A Jupyter Notebook (`.ipynb`) containing the full analysis and modelling workflow
- An exported HTML version of the notebook for easier review and presentation

## What I worked on

- Model comparison
- Hyperparameter tuning
- Performance evaluation
- Interpretation of predictive results
- Structured notebook development

## Tools used

- Python
- scikit-learn
- Jupyter Notebook

## What I learned

This project helped me better understand how to compare models in a structured way, evaluate performance trade-offs, and explore how ensemble methods can improve predictive results beyond individual models.
